# P-DX 출퇴근 기록부

순수 HTML/CSS/JS로만 만든 출퇴근 시간 기록 프로그램입니다.
서버·설치 없이 동작하며, PWA를 지원해 휴대폰에 앱처럼 설치할 수 있습니다.

## 사용법

### PC (사내망)

`index.html`을 더블클릭해서 브라우저로 열면 끝입니다.
하단 **"파일에 저장 연결"**을 눌러두면 기록이 진짜 JSON 파일에도 자동 저장됩니다 (권장).

### 휴대폰 (iOS / Android 공통)

이 폴더를 https 정적 호스팅(GitHub Pages 등)에 올린 뒤 폰 브라우저로 접속:

- **iPhone**: Safari → 공유 → **홈 화면에 추가**
- **Android**: Chrome → 메뉴 → **앱 설치**

설치 후에는 오프라인에서도 동작합니다.

## 기능

- **출근/퇴근 도장** — 현재 시각이 **30분 단위 내림**으로 기록됩니다
  (14:45 → 14:30, 13:15 → 13:00). 이미 기록이 있으면 덮어쓸지 물어봅니다.
- **달력** — 일자별 출/퇴근 시각과 기준 대비 ±, 월 누적 표시. 날짜를 누르면 직접 수정.
  수정 시각도 30분 단위로 맞춰집니다.
- **기준 근무시간** — 기본 09:00~18:00. ± = (실제 근무) − (기준 근무).
- **자정 넘는 근무** — 퇴근이 출근보다 이르면 익일 퇴근(+1)로 계산.
  자정 넘겨 퇴근 도장을 누르면 "어제 기록으로 저장"을 제안합니다.

## 저장 방식

- 기록은 기기의 localStorage에 저장되고 **IndexedDB에 이중 미러링**됩니다
  — 한쪽이 지워져도 다른 쪽에서 자동 복구합니다.
- 설치형 홈 화면 앱은 브라우저 임시 데이터 정리의 영향을 거의 받지 않으며,
  `storage.persist()`로 영구 보존을 요청합니다.
- PC에서는 "파일에 저장 연결"로 JSON 파일에도 실시간 저장할 수 있습니다 (3중 보관).

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 + PWA 메타 |
| `style.css` | 디자인 (외부 폰트/CDN 없음) |
| `app.js` | 기록·달력·저장 로직 |
| `manifest.json` / `sw.js` / `icons/` | PWA 설치·오프라인 지원 |

코드 수정 시 `sw.js`의 `CACHE` 버전 문자열을 올려야 설치된 앱에 반영됩니다.
